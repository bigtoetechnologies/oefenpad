## Cut on 10 November 2026

`kiezen-tussen-deuren.png` — batch 4b, Set A #4, briefed and drawn, then cut.
The chunk `kiezen tussen` is correct Dutch (`kiezen tussen twee kwaden`), so
this is not a language error. It was the wrong frame for that set:

1. `tussen` is literal in this scene — the person is physically between two
   doors — so it teaches no fixed preposition, which is what batch 4b exists to
   teach.
2. `tussen` belongs to the A2+ spatial band (`tussen-twee-mensen.png`); framing
   it in 4b pulled it four batches early.
3. The drawing duplicated A2+ #74 `twijfelen-tussen-twee-jassen.png` — same
   composition, same hand-on-chin gesture, different chunk.
4. `kiezen tussen` is already scheduled at B1+ #111, paired with
   `kiezen-uit-het-aanbod`, which is the contrast that actually teaches it.

Full reasoning for that cut: `Docs/voorzetselpaden/a2-pairs.html`, in the collapsible *Plan en kaders*
section, under *Why `kiezen tussen` was dropped*.

Keep these files out of `assets/voorzetselpaden/` and out of
`prepositions.json`. The old `incoming/` variants of the two replaced scenes are
provenance only and must not be used either.
